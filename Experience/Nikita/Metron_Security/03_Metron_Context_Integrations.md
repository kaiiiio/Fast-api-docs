# Metron Security Context & Domain Knowledge

To impress in the interview, you need to understand *what* they actually do.

## 🏢 What does Metron do?
They are an **Integration Service Provider**. While other companies build *one* product, Metron builds the **Glue** that connects hundreds of products like:
- **SIEM:** Splunk, IBM QRadar (Log management).
- **EDR:** CrowdStrike, Cybereason (Endpoint protection).
- **ITSM:** ServiceNow (Ticket management).

## 🚀 Key Value Propositions
1.  **Automation:** If a threat is detected in CrowdStrike, Metron’s code automatically creates a ticket in ServiceNow and blocks the IP in the Firewall.
2.  **Scalability:** They work with **250+ platforms**. This means their code has to be extremely modular.
