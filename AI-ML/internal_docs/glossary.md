# Glossary — Quick definitions

- Embedding: A fixed-size numeric vector representing an input (text, image).
- Vector store: A database of embeddings + metadata used for retrieval.
- ANN: Approximate Nearest Neighbor — algorithms for fast similarity search.
- Cosine similarity: A measure of angle/direction similarity between vectors.
- Dot product: Sum of elementwise multiplications between two vectors.
- Chunking: Splitting documents into smaller pieces for embedding.
- RAG: Retrieval-Augmented Generation — combines retrieval with generation.
- LLM: Large Language Model — transformer-based models trained on large corpora.
