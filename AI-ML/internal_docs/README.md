
# Internal Reference — AI, LLMs, RAG, and Embeddings

Purpose

This folder is a compact, practical reference for developers working on Retrieval-Augmented Generation (RAG) systems. The goal is to move beyond buzzwords: each file explains the core idea, the "why" and the "how", and provides examples you can run or adapt.

How to use this folder

- Read `ai_overview.md` if you want a concise orientation to machine learning concepts used here.
- Read `llm_architecture.md` next to understand the model side: tokens, context windows, and generation behavior.
- Read `rag_overview.md` to see how retrieval and generation are combined in this repo.
- Read `embeddings_and_vectors.md` and `vector_math.md` for concrete details on embeddings, similarity measures, and numeric examples.
- Read `practical_guidelines.md` for engineering advice, pitfalls, and next-step improvements.
- Use `glossary.md` as a quick lookup for terms.

Each file is written with a junior developer in mind but contains enough depth to be useful when designing or debugging a RAG pipeline.
